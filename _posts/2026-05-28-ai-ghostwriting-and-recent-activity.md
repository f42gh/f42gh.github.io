# ブログ書くの億劫すぎてAIに代筆してもらいます

> [author: threat(claude code agent)]

ブログって書くのがしんどい。「何を書くか」より「書く気を出す」のが一番のボトルネック。

なので、**AIに代筆してもらうことにした**。

---

## AI秘書「スレート」をセットアップした

Claude Code（Anthropic のターミナル上で動く AI エージェント）を、Telegram ボット経由で常駐させる構成を作った。名前は **threat**（スレート）。

仕組みはシンプルで、`boot.sh` が Claude Code を Telegram プラグイン付きで起動し続けるだけ。落ちたら5秒後に自動再起動する。

```sh
claude --dangerously-skip-permissions --channels plugin:telegram@claude-plugins-official -c
```

Telegram からメッセージを送ると Claude Code が応答する。ファイルを読んだり、GitHub APIを叩いたり、コードを書いたり、ブログ記事（この記事もそう）を書いたりしてくれる。

WSL でのセットアップはそれなりにハマりポイントがあったので、[前の記事](/2026/05/28/claude-code-telegram-wsl-setup.html)に詳しく書いた。

## 最近のコミット、ざっくり

せっかくなので直近の活動も共有しておく。

### `jh`（就活ダッシュボード）

28卒就活用のローカルアプリ。FastAPI + SQLite のバックエンドに Svelte フロントを繋いでいる。今週、Svelte ブランチを切って PR → マージまでやった。企業・選考機会・次アクションを一元管理できる。自分の就活データを自分で作ったツールで管理するのが気持ちいい。

### `ds` / `cs`（学習ノート）

データサイエンスと CS の知識をMarkdownでストックしているプライベートリポ。今週新たに作った。回帰分析・SVM・NN あたりを書き溜めてる。いつか公開記事にしたい。

### `atcoder` / `cpp`（競プロ）

AtCoder の提出履歴と C++ の練習コード。評価21で止まってるのでそろそろ動かしたい。

### `jikko.v`（タスク管理アプリ）

「今やるべきことを1件に絞る」という思想のデスクトップアプリ。Tauri + Svelte + SQLite の構成。OODA ループ（Observe → Orient → Decide → Act）をタスク管理に応用している。

## ブログはこういう感じでやっていく

アウトプットしたいけどブログを書く気が出ない、という矛盾を AI に外注することで解決した。スレートには GitHub を読む権限があるので、コミット履歴とメモから記事を生成してもらえる。
